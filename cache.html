整行浅黄色（关注）：输入合计至少 1,000 Token 且缓存率 50%–90%，或单次费用 ≥$0.01，或首字延迟 ≥10 秒，或耗时 ≥60 秒。整行浅橙色（较慢）：首字延迟 30–60 秒，或总耗时 180–300 秒。整行浅红色：输入合计至少 1,000 Token 且缓存率低于 50%，或单次费用 ≥$0.05，或首字延迟 ≥60 秒，或耗时 ≥300 秒。规则用于筛查指标，不代表请求失败或模型真假；短请求、首次请求低缓存可能正常。

缓存写入指新建缓存时单独记录的 Token；当前 GPT 用量不单列展示，CSV 仍保留原始字段。缓存写入 0 表示站点上游的 cache_creation_tokens 返回 0；GPT 请求可能只报告缓存读取，不单列缓存写入，不能据此判断未建立缓存。

缓存率根据站点返回的计费记录计算，不是对上游实际缓存或模型身份的独立验证。长对话反复发送相同上下文，出现 99% 缓存率可能正常。分钟筛选使用北京时间，结束分钟包含整分钟；超过 10,000 条时请缩短范围。只读站点已记录的请求，通常在请求结束后出现，刷新间隔 10 秒。汇总遵循上方选择的模型、分组和日期；指标提醒筛选与排序仅影响当前页明细。上游用量接口未提供 HTTP 状态或成功/失败标记，本看板不据颜色判定请求状态；是否错误扣费需要结合客户端报错、请求 ID 和中转站后台核查。缺失字段显示 —。金额为上游记录的实际扣费（美元），余额最多缓存 2 分钟。

添加中转站

从编辑器已保存的站点中搜索选择，填入该站官网登录后的 JWT 令牌即可。

选择站点

先搜索并点击选择一个站点。

令牌加密保存在服务器；仅用于读取该站点的用量数据。

如何获取登录令牌？
  1. 先打开所选站点并登录。
  2. 按 F12 打开开发者工具，进入“网络（Network）”，刷新页面并点开一个用户信息或用量请求。
  3. 在“请求标头（Request Headers）”找到 Authorization: Bearer …，复制 Bearer 后面的内容粘贴到上方。
  4. 若请求标头没有令牌，可在“应用（Application）→本地存储（Local Storage）”查找 access_token 或 token。

这里只需要网页登录 JWT，不要填写以 sk- 开头的模型 API 密钥，也不要把令牌发给他人。

连接站点

使用站点官网登录后获取的 JWT 令牌。连接与令牌分别加密保存在服务器，同一 LinX 账号可跨设备查询。仅支持 Sub2API 兼容用量接口，不发起模型请求。

遇到验证码时，请先在 站点官网登录，再填入该登录会话的令牌。不要填写模型 API Key。若 API 请求本身被 Cloudflare 拦截，JWT 也不能绕过该验证。
