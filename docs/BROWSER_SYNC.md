# 浏览器自动同步登录

适用于 Chrome / Edge 桌面浏览器、Sub2API 和提供 Bearer 访问令牌的 New API 站点。两类站点使用相同的用量页面、筛选、趋势、日历和日报。官网页面保持登录时，扩展每分钟检查新的网页登录令牌，New API 官网发起账户或日志请求时也会同步更新。无需把密码交给扩展，也不会调用模型产生费用。

## 首次安装

1. 在 LinX **用量与缓存** 页面左侧点击 **自动同步登录**，下载扩展 ZIP。
2. 解压到固定文件夹；不要删除这个文件夹。
3. 在日常登录中转站的浏览器里打开 chrome://extensions 或 edge://extensions，开启「开发者模式」，点击「加载已解压的扩展程序」，选中解压后的 linx-browser-sync 文件夹。不是选择 ZIP 文件。页面安装指南提供入口；已配对扩展可帮你打开，未安装时会复制地址或提示粘贴到地址栏。
4. 回到用量页面生成配对码。打开扩展，输入自己的监测网站 HTTPS 地址和配对码。配对码 5 分钟有效，只能使用一次。
5. 点击 **授权站点**，在浏览器的权限提示中同意访问自己已经添加的站点。
6. 保持这些站点的官网页面打开并登录。扩展会显示每站的同步结果。

## 日常使用

- **首次快速连接**：在“添加中转站”中选中站点，点击“从已打开的官网获取并连接”。同一浏览器里保持该站官网已登录，扩展会直接将令牌交给监测服务器验证并加密保存，不需要复制粘贴。
- **1.1.1 授权后自动继续**：首次连接尚未授权的站点时，保持用量页的连接窗口打开，在扩展里点击“授权站点”。授权后会自动继续你刚发起的连接，不用回来重复点按钮。请求 90 秒有效，超时后需重新点击。读取权限由浏览器弹窗授权，网页不能替你授予。
- 已安装旧版的用户：重新下载 ZIP，覆盖原扩展目录文件，在 chrome://extensions 或 edge://extensions 点击该扩展的重新加载，然后刷新用量页面。配对信息保留在浏览器扩展存储中，无需移除扩展后重装。
- 使用扩展 **1.1.2+**，并与当前监测网站配对，官网和用量页位于同一浏览器。未检测到扩展、官网未打开、未登录或尚未授权时，页面会显示对应提示，也可继续手动填写令牌。
- **New API（包括 FreeGG 当前面板）**：访问令牌可能只保存在官网内存中。更新扩展后刷新一次已登录官网，或在用量页点击“获取并连接”。没有已观察到的令牌时，这个按钮会刷新所选官网一次，读取官网自己发出的账户/日志请求中的 Bearer 访问令牌。后台日常同步不会主动刷新官网，也不会调用官网的刷新登录接口或上传 Cookie。
- 扩展仅在已添加并授权站点注入登录观察脚本，读取官网自己发出的固定账户/日志接口的 Authorization 字段，忽略其他来源和模型接口，不读取响应体或 Cookie。令牌仅在官网和扩展工作进程内存中暂存，重启或休眠后可通过官网正常请求重新获取。
- 仅 Cookie 登录、未提供可用 Bearer 访问令牌的旧版 New API 面板，暂不能自动获取；需要该站提供的有效访问令牌。服务端也可能被站点 Cloudflare/访问限制阻挡，浏览器登录态不能绕过这些限制。
- 1.1.2 将登录连接与慢速用量查询分离；直接复用验证结果，页面同时核对服务器连接任务，扩展结果消息丢失时也能恢复成功状态。
- 检查按站点并行进行，各站结果完成即更新；慢站不会阻塞其他站。重复检查复用正在执行的任务，站点列表短时缓存避免重复读取；弹窗实时显示进度并在结束后显示“检查完成”。
- 不必一直停留在官网或用量页；浏览器需要保持运行，官网标签页不能被完全关闭或丢弃。休眠、浏览器退出、网站退出登录或验证码都不能靠扩展自动解决。
- 官网本身没有续期、会话被撤销时，需要先在官网重新登录；新令牌随后自动同步。扩展不会自动填写密码、绕过 Cloudflare 或登录验证。
- 用量页每 10 秒检查连接变化；旧连接失效后，也能在新令牌到达时恢复显示。
- Sub2API 读取授权站点的固定登录字段，优先支持 auth_token，兼容 access_token、accessToken、token；New API 还可观察官网自己发出的 Bearer 访问令牌。不遍历其他网站的存储，不读取密码或模型 API Key，不上传浏览器的刷新令牌，以免两端轮换冲突。
- 令牌只发送到已配对的监测服务器，验证账户身份一致后加密保存。扩展仅持久保存设备连接密钥及令牌指纹，不持久保存站点 JWT。
- 默认继续使用原来的账户。官网切换到另一账户时会提示账户不一致，需要在用量页手动连接；不会静默更换账户。
- 在用量页手动「断开连接」后，扩展不会自动重连该站。可在扩展暂停同步，或在用量页面移除浏览器设备以立即撤销权限。

## 服务器及开源安装

功能文件：browser_sync.py、browser-sync-ui.js 和 integrations/browser-sync/。扩展下载由已登录的服务器动态打包，不包含站点令牌或个人数据。配对状态保存在服务器私有数据目录 usage-private/browser-sync.json，设备密钥与配对码仅保存哈希；该目录不可发布。

New API 适配位于 usage_newapi.py：通过账户自己的 /api/user/self、/api/user/self/groups、/api/log/self 和公开 /api/status 只读查询。消费日志按上海时区筛选，分页并行读取并合并，列表、汇总及曲线共享短时缓存；单次最多 10,000 条，超出请缩小日期范围。费用使用该站实际 quota_per_unit 换算，缺失比例时留空。OpenAI 口径输入包含缓存，Anthropic 口径输入不含缓存，统一后按输入 Token 加权计算缓存率；缺失缓存指标显示“—”，不会当成 0。逐天统计也遵循相同口径。

首次快速连接由已登录管理员创建 90 秒有效的一次性连接请求。扩展仅接受来自已配对监测页面的请求，并检查所选站点的浏览器授权。令牌从扩展直接发送服务器，不回填网页；服务器验证站点来源、请求和账户身份。日常后台同步仍不能擅自重连已手动断开的站点，已连接账户也不会被其他账户静默替换。

扩展不依赖 Cindy 持续运行，不需要远程调试端口。它需要你在实际登录中转站的浏览器里安装一次，监测网页本身无法跨域读取其他网站的登录存储。
