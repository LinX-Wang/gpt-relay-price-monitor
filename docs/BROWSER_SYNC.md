# 浏览器自动同步登录

适用于 Chrome / Edge 桌面浏览器和 Sub2API 兼容站点。官网页面保持登录时，扩展每分钟检查一次新的网页登录令牌，并自动更新自己的 LinX 用量连接。打开或切换标签页时也会触发检查。无需把密码交给扩展，也不会调用模型产生费用。

## 首次安装

1. 在 LinX **用量与缓存** 页面左侧点击 **自动同步登录**，下载扩展 ZIP。
2. 解压到固定文件夹；不要删除这个文件夹。
3. 在日常登录中转站的浏览器里打开 chrome://extensions 或 edge://extensions，开启「开发者模式」，点击「加载已解压的扩展程序」，选中解压后的 linx-browser-sync 文件夹。不是选择 ZIP 文件。
4. 回到用量页面生成配对码。打开扩展，输入自己的监测网站 HTTPS 地址和配对码。配对码 5 分钟有效，只能使用一次。
5. 点击 **授权站点**，在浏览器的权限提示中同意访问自己已经添加的站点。
6. 保持这些站点的官网页面打开并登录。扩展会显示每站的同步结果。

## 日常使用

- **1.1.0 新增首次快速连接**：在“添加中转站”中选中站点，点击“从已打开的官网获取并连接”。同一浏览器里保持该站官网已登录，扩展会直接将令牌交给监测服务器验证并加密保存，不需要复制粘贴。
- 新站第一次使用时，先点击上述按钮将站点加入用量列表，再在扩展中点击“授权站点”，回来再次获取即可。读取权限由浏览器弹窗授权，网页不能替你授予。
- 已安装旧版的用户：重新下载 ZIP，覆盖原扩展目录文件，在 chrome://extensions 或 edge://extensions 点击该扩展的重新加载，然后刷新用量页面。配对信息保留在浏览器扩展存储中，无需移除扩展后重装。
- 快速连接需要扩展 1.1.0+ 已与当前监测网站配对，且官网和用量页位于同一浏览器。未检测到扩展、官网未打开、未登录或尚未授权时，页面会显示对应提示，也可继续手动填写令牌。
- 不必一直停留在官网或用量页；浏览器需要保持运行，官网标签页不能被完全关闭或丢弃。休眠、浏览器退出、网站退出登录或验证码都不能靠扩展自动解决。
- 官网本身没有续期、会话被撤销时，需要先在官网重新登录；新令牌随后自动同步。扩展不会自动填写密码、绕过 Cloudflare 或登录验证。
- 用量页每 10 秒检查连接变化；旧连接失效后，也能在新令牌到达时恢复显示。
- 扩展只读取授权站点的固定登录字段，优先支持 Sub2API 的 auth_token，兼容 access_token、accessToken、token。不遍历其他网站的存储，不读取密码或模型 API Key，不上传浏览器的刷新令牌，以免两端轮换冲突。
- 令牌只发送到已配对的监测服务器，验证账户身份一致后加密保存。扩展仅持久保存设备连接密钥及令牌指纹，不持久保存站点 JWT。
- 默认继续使用原来的账户。官网切换到另一账户时会提示账户不一致，需要在用量页手动连接；不会静默更换账户。
- 在用量页手动「断开连接」后，扩展不会自动重连该站。可在扩展暂停同步，或在用量页面移除浏览器设备以立即撤销权限。

## 服务器及开源安装

功能文件：browser_sync.py、browser-sync-ui.js 和 integrations/browser-sync/。扩展下载由已登录的服务器动态打包，不包含站点令牌或个人数据。配对状态保存在服务器私有数据目录 usage-private/browser-sync.json，设备密钥与配对码仅保存哈希；该目录不可发布。

首次快速连接由已登录管理员创建 90 秒有效的一次性连接请求。扩展仅接受来自已配对监测页面的请求，并检查所选站点的浏览器授权。令牌从扩展直接发送服务器，不回填网页；服务器验证站点来源、请求和账户身份。日常后台同步仍不能擅自重连已手动断开的站点，已连接账户也不会被其他账户静默替换。

扩展不依赖 Cindy 持续运行，不需要远程调试端口。它需要你在实际登录中转站的浏览器里安装一次，监测网页本身无法跨域读取其他网站的登录存储。
