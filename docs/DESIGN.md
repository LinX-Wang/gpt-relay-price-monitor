# 字体与出品标识

共享主题采用 Inter（英文界面）、Noto Sans SC（中文界面）、JetBrains Mono（金额、倍率、百分比、Token、耗时与部分模型标签）。LinX JetBrains Mono 是加载别名。

字体子集内嵌于 theme.css，随项目部署，不依赖在线字体 CDN。扩展界面时需补全字库覆盖；未覆盖文字使用系统字体。字体许可保留于 assets/*LICENSE.txt、assets/JetBrainsMono-OFL.txt。

LinX 出品是出品方品牌署名。浅色背景使用 assets/linx-v3-lockup_color.svg，深色背景使用 assets/linx-v3-lockup_white.svg。SVG 已转成路径，不依赖字体。保持原始宽高比，低调展示于登录页、侧栏底部或页脚。

每款软件保留自己的名称、应用图标和 favicon。出品标识不替换产品图标，也不表示对任何中转站的背书。衍生项目应使用自己的产品标识，避免与原项目官方出品混淆。
