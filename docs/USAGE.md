# 用量监测与数据中心

## 连接与切换站点

在用量页面点击“添加中转站”，搜索编辑器已保存的站点，再填写该站的官网登录令牌。顶部“监测站点”选择当前展示的中转站，图标从对应站点自动获取；无法读取图标时显示站名首字。

需要减少手动更新令牌时，使用 [浏览器自动同步登录](BROWSER_SYNC.md)。账号连接在服务器加密保存；默认管理员访问共享数据。

## 记录列表

默认日期为今天，支持模型、分组、精确到分钟的日期范围、分页与 CSV 导出。记录读取默认每 10 秒刷新，更新令牌后重新读取；后台标签页受到浏览器休眠、节流和冻结限制，返回页面时补刷。

缓存率、费用、首字延迟与总耗时按规则着色。颜色提醒反映这些指标，不代表请求失败。缓存率按“缓存读取 Token ÷ 全部输入 Token”计算，不能据此判断模型真伪或请求成功率。缓存写入只有站点返回对应字段时才有意义，零值本身不足以判断中转站存在问题。

## 数据曲线入口

点击页面顶部“数据曲线”，打开用量数据中心。关闭按钮或 Esc 返回原页面，原有主布局保持不变。三个视图均跟随当前站点、模型及分组；日历和日报的范围标签显示对应图标。

| 视图 | 内容 |
| --- | --- |
| 趋势曲线 | Token、请求数或费用与缓存率；7 天、30 天或记录页所选日期；悬停查看每天数值 |
| 用量日历 | 按月查看，每天颜色与条形长度表示当前指标；月度汇总；点击一天查看概览 |
| 自动日报 | 选择日期查看用量、缓存率、请求数和费用；缓存复用进度；近 7 日节奏与汇总 |

日聚合以北京时间为准，日期筛选按完整自然日统计。日报中完整日期与前一日比较；今天展示截至读取时的累计值，避免与昨日全天直接比较。缺失日期保留为空，只有站点明确返回零才显示 0。月度与近 7 日汇总以已返回统计为基础。

## 读取速度与自动更新

曲线在后台预取当前统计，并为日历和日报准备可共享的日期范围。同一站点、连接身份、模型及分组下，三个视图复用数据和进行中的请求，同月选日无需单独请求。服务器同时复用覆盖日期范围的有效缓存，并合并相同并发查询。缓存有效期为 60 秒，页面按需刷新。

首次读取未缓存范围的耗时取决于上游。当前适配 Sub2API 风格的逐天聚合接口，不通过逐条分页拼凑日统计；未提供兼容接口的站点会显示说明。

自动日报在站内根据统计生成，不调用额外模型，也不发送邮件或外部推送。
